# LayoutEditor 修改摘要

## v2.8.2 (2026-05-18)
- **标尺透明背景**：去掉标尺背景色和边框，直接浮在画布网格上方
- **标尺随缩放**：刻度步长和数值随 zoom 动态调整，缩放时刻度密度合理
- **标尺可读性**：文字颜色提亮至 75% 白色，字号从 8px 增至 9px，刻度线更清晰

## v2.8.1 (2026-05-17)
- **修复标尺布局**：标尺从 fixed 定位改为 CSS Grid + sticky，嵌入画布内部跟随滚动
- **修复组件树图标**：修复 type-icon span 缺少 `>` 闭合标签的 bug
- **标尺尺寸优化**：从 30px 缩小到 24px，更紧凑
- **画布内容区域**：新增 canvas-content 容器，min-size 2000x2000px

## v2.8.0 (2026-05-17)
- **代码重构**：DOM查询引入 $/$$ 缓存函数（替换78处）
- **代码重构**：renderComponentContent 473行巨型函数拆分为24个独立渲染器
- **代码重构**：合并相似函数（undo/redo、moveUp/down、drawRulerH/V、parseXMLNode/Element）
- **代码重构**：提取 clearDropTargets、createDragGhostHTML 工具函数
- **移除JSZip**：删除未使用的外部CDN依赖，项目零外部依赖
- **新增功能**：代码编辑器XML语法高亮 + 行号
- **新增功能**：状态栏增强（缩放比例、选中组件类型、视图模式）
- **新增功能**：属性面板批量修改（背景色/文字颜色应用到子组件）
- **安全增强**：清空画布和键盘删除添加确认对话框

## v2.7.5 (2026-05-17)
- **新增**：代码编辑器XML语法高亮、行号显示、滚动同步

- **新增**：属性面板批量修改功能
