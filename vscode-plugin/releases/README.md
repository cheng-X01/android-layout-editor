## 安装方法

1. 下载 `.vsix` 文件
2. VS Code 中按 `Ctrl+Shift+P` → "Extensions: Install from VSIX"
3. 选择下载的 `.vsix` 文件

## 功能特性

- 可视化 XML 布局编辑器
- H5 (HTML/CSS) 转 Android XML
- Material 3 动态主题
- 8 种设备预设预览
- XML 格式化与验证
- 资源自动补全
- 性能分析面板
- 布局边界可视化

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+F` | 格式化 XML |
| `Ctrl+Shift+H` | H5 转 Android XML |
| `Ctrl+Shift+P` | 显示性能分析 |
| `Ctrl+Shift+W` | 包裹为布局 |
| `Ctrl+Shift+U` | 解包布局 |
